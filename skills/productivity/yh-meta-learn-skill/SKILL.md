# 学习 Skill（Meta Learn）

快速理解任意已安装 Skill 的能力、用法和效果。

## 输入

用户提供一个 skill 名称（从已安装列表中选择）。

## 工作流程

### 1. 加载目标 Skill

使用 Skill 工具调用目标 skill，读取其完整定义（包括引用的子文件）。

### 2. 生成速读卡

用以下模板输出：

```
## [Skill Name] 速读卡

### 解决什么问题
（一句话概括）

### 什么时候该用
- 触发场景 1
- 触发场景 2
- …

### 两种/N种模式（如有分支）
| 模式 | 适用场景 | 产出物 |
|------|---------|--------|

### 工作流程概览
1. → 2. → 3. → …（简明步骤链）

### 核心原则
- 要点 1
- 要点 2

### 一个具体使用示例
> 你说："…"
> → 触发什么 → Claude 做什么 → 产出什么
```

### 3. 询问是否演示

问用户："想实际跑一个小 demo 体验效果吗？"

如果用户同意，构造一个贴合该 skill 的小场景，实际触发 skill 走一遍流程。

## 注意事项

- 如果 skill 有子文件（如 LOGIC.md、UI.md、REFERENCE.md），也要读取以获得完整理解
- 速读卡应该用中文输出（除非用户明确要求英文）
- 演示场景应该足够小（5分钟内完成），但要能展示 skill 的核心价值
- 不要只念定义——要用自己的话总结，让用户一眼看懂
